# Start Here

This is Version 1 of the paycheck-first budget app.

## What works now

The source is complete and your starter budget is already loaded in `src/data.js`.

The app intentionally uses browser local storage in Version 1. That means you can test the budgeting workflow before connecting Firebase or creating accounts.

## When we go step by step

We will do this in order:

1. Install Node.js / verify it is installed.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Test the budget workflow.
6. Create the GitHub repository.
7. Create the Firebase project.
8. Add Firebase Authentication and Firestore.
9. Deploy it.

You do not need to do any of that until we walk through it together.
